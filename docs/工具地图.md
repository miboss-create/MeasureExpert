# MeasureExpert 工具地图

> 版本：V1.5  
> 产品形态：**工具箱 + 配方流水线**  
> 技术主线：1D Measuring 卡尺族；2D Metrology 整包后置（V2）

---

## 1. 两层架构

| 层 | 职责 | 交互 |
|----|------|------|
| 工具箱 | 单工具：画 ROI → 试跑 → 看几何/标量 | 主图叠加 + 结果表 |
| 配方流水线 | 有序步骤：定位 → 几何工具 → 派生 → 公差 | 位姿跟随 + CSV/OKNG |

原则：**一个能力一个工具**；HALCON 例程只作验收数据集，不做「一例程一菜单」。

---

## 2. V1.5 范围冻结（已确认）

### 2.1 纳入

| 工具 ID | 名称 | 输入 | 输出 | 公差 |
|---------|------|------|------|------|
| Alignment | 形状定位 | 图像 + 模型 | 位姿 HomMat2D + 轮廓 | — |
| FindLine | 找线 | 矩形卡尺 ROI + 位姿 | 直线段 + 边缘点 | 找到即合格（中间量） |
| FindCircle | 找圆 | 圆弧卡尺 ROI + 位姿 | 圆心/半径 + 边缘点 | 找到即合格（中间量） |
| CaliperWidth | 卡尺宽度 | 矩形卡尺 + 位姿 | 宽度标量 + 边缘对 | 标量 |
| CaliperDiameter | 卡尺直径 | 同宽度 | 直径标量 | 标量 |
| PointToLine | 点到线距 | 引用两点源（圆/交点）+ 线 | 距离标量 | 标量 |
| LineIntersection | 两线交点 | 引用两条找线 | 交点 | 找到即合格 |
| Angle | 两线夹角 | 引用两条找线 | 角度（度） | 标量 |
| PointDistance | 两点距 | 引用两几何点 | 距离标量 | 标量 |

### 2.2 明确暂缓（不进 V1.5）

- 完整 2D Metrology 模型、模糊测量、多目标定位
- 相机/PLC 实装、世界坐标标定板全流程
- 「一个例程一个专用对话框」

## 3. 能力 ↔ HALCON 对应

| 能力 | 典型算子 | 验收例程方向 |
|------|----------|--------------|
| 定位 | `create_shape_model` / `find_shape_model` | `first_example_shape_matching`、board |
| 找边点 | `measure_pos` | `gen_measure_rectangle2` |
| 找线 | `measure_pos` + `fit_line_contour_xld` | 金属直边 / fuse |
| 找圆 | `gen_measure_arc` + `measure_pos` + `fit_circle_contour_xld` | `measure_arc` / circles |
| 宽度 | `measure_pairs` | `pm_measure_board` |
| 派生 | 解析几何（交点、点线距、夹角） | 组合上表工具 |

## 4. 学习 / 实现顺序（勿并行堆）

```
L0 认知 → L1 找边点(内含于找线) → L2 找线 → L3 找圆
         → L4 宽度(已有) → L5 位姿跟随(已有) → L6 派生与公差
```

每阶段验收：HDevelop 同图同量级 → 本软件试跑叠加一致。

---

## 5. 配方约定

1. 步骤按列表顺序执行；派生项必须引用**更靠前**步骤的 `id`。
2. 几何 ROI 存**相对模板**坐标；运行时用定位 HomMat2D 变换到图像坐标。
3. 找线/找圆既可单独验收，也可作为派生输入；宽度/直径不依赖找线结果。
