# 第三方依赖（不入库）

`3rdParty/` **整目录已加入 `.gitignore`，不要提交到仓库。**

克隆代码后，请在仓库根目录自行准备：

```text
3rdParty/
  Halcon/
    include/
    lib/x64-win64/          # halcon.lib / halconcpp.lib 等
  OpenCV/                   # OpenCV 的 build 目录（含 OpenCVConfig.cmake）
```

## HALCON

将本机 HALCON 的头文件与库放到 `3rdParty/Halcon`，结构与官方安装中的 `include`、`lib/<arch>` 一致即可。

运行程序仍需本机授权版 DLL，把安装目录的 `bin\<arch>` 加入 `PATH`。

## OpenCV（与烛照相同：`find_package(OpenCV)`）

任选其一：

1. **目录联接（推荐）**

```bat
mklink /J 3rdParty\OpenCV <你的OpenCV>\opencv\build
```

2. 把官方 `build` 目录整体拷到 `3rdParty/OpenCV`
3. 在 CMake / Qt Creator 中设置 `OpenCV_DIR` 为含 `OpenCVConfig.cmake` 的目录  
   （常见为 `<build>` 或 `<build>/x64/vc16/lib`）

构建成功后，`opencv_world*.dll` 会自动拷到 `../MeasureExpert_runtime`。
